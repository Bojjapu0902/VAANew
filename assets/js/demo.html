Z ZoomView
gsap-zoomview v1.0.0
GSAP ScrollTrigger plugin

Soft zoom,
driven by a class.

Add .zoom-view to any image. It eases out to its natural scale as it enters the viewport, rests while it's on screen, then eases back in as it leaves — scrubbed to scroll position, so it reverses perfectly and never fights the user.

1 class, zero markup changes Auto-wrapped overflow mask Per-element data-* overrides Respects reduced motion
Per-element tuning

Three intensities, same class.

Every option has a data-zoom-* twin, so a gallery can breathe differently from a hero without touching a line of JavaScript.

Restrained

data-zoom-scale="1.08" — barely perceptible, ideal for dense grids and text-heavy pages.

Default

The shipped preset. Enough movement to feel intentional, not enough to pull focus from the content.

Editorial

scale 1.34 with a longer plateau and scrub="0.8" smoothing — cinematic, for full-width features.

Pattern 02

Bring your own wrapper.

Put the class on the image and the plugin generates the mask for you — inheriting its border radius. Put it on a wrapper you already style, and that wrapper becomes the mask instead. Both paths are idempotent, so re-running ZoomView.init() after a route change is safe.

Source-agnostic

Any image. Including the ones that aren't photos.

The plugin only ever touches transform on whatever sits inside the mask — raster, SVG, data URI, <video>, <canvas>. No dependency on the source or its intrinsic size.

Implementation

Drop in, ship.

1 · Load GSAP, ScrollTrigger, then the plugin

<script src="https://cdnjs.cloudflare.com/ajax/libs/gsap/3.13.0/gsap.min.js"></script>
<script src="https://cdnjs.cloudflare.com/ajax/libs/gsap/3.13.0/ScrollTrigger.min.js"></script>
<script src="gsap-zoomview.js"></script>

<!-- that's it. Every .zoom-view is wired on DOMContentLoaded. -->

2 · Add the class

<!-- plugin creates the overflow mask and inherits the radius -->
<img class="zoom-view" src="hero.jpg" alt="">

<!-- or mask it yourself -->
<div class="zoom-view" data-zoom-ratio="16/9">
  <img src="hero.jpg" alt="">
</div>

3 · Tune globally or per element

// before init — becomes the baseline for every instance
ZoomView.config({ scale: 1.14, hold: 0.7, easeIn: 'power3.out' });

// SPA / Next.js: re-run after the route's images mount, then clean up
ZoomView.init();
ZoomView.observe();              // auto-wire images injected later
ZoomView.refresh();              // after layout shifts
ZoomView.destroy();              // on unmount — unwraps and kills triggers

// single element, explicit options (data-* still wins)
ZoomView.create(document.querySelector('#feature'), { scale: 1.3 });

Options

AttributeDefaultWhat it controls
data-zoom-scale1.18Scale while the image sits outside the viewport — the "zoomed in" end of the range.
data-zoom-rest1Scale at rest, once the image is centred. Set above 1 if you want it to never fully relax.
data-zoom-hold0.55Length of the plateau at rest scale, relative to one ramp. 0 removes the pause entirely.
data-zoom-ease-inpower2.outEase applied while entering — decelerating reads as "settling".
data-zoom-ease-outpower2.inEase applied while leaving — accelerating reads as "pulling away".
data-zoom-scrubtruetrue locks scale to scroll position; a number (e.g. 0.8) adds that many seconds of catch-up smoothing.
data-zoom-starttop bottomScrollTrigger start — where the ramp begins.
data-zoom-endbottom topScrollTrigger end — where the ramp finishes.
data-zoom-origin50% 50%transform-origin of the zoom. Anchor to an edge to bias the crop.
data-zoom-ratio—16/9 sets the mask's aspect ratio; fill makes it fill a height you control; omit for the image's natural ratio.
data-zoom-wraptrueSet false to skip auto-wrapping and scale the element in place.
data-zoom-markersfalseScrollTrigger debug markers for this element.

Notes worth knowing

Because the range runs top bottom → bottom top, an image taller than the viewport gets a longer ramp automatically — no per-element math. Under prefers-reduced-motion: reduce the timeline is never built and GSAP reverts every inline transform, so the markup is left clean rather than frozen mid-zoom. Only transform animates, so each instance stays on the compositor; will-change is set on init and cleared on destroy.

gsap-zoomview · MIT · requires GSAP 3 + ScrollTrigger Scroll up and down — the scrub reverses exactly.
